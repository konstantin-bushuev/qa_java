# Feline Classes Unit Testing

## Описание проекта

- Редактирование кода класса и создание нового класса с применением инъекции зависимостей.
- Юнит-тесты для основных классов.

### Цель проекта

Разработка юнит-тестов для основных классов с применением инъекции зависимостей и проверкой покрытия кода

### Тип тестирования

Unit testing

### Реализованные задачи

- Исправлен класс Lion с применением инъекции зависимостей.
- Создан новый класс LionAlex.
- Разработаны юнит-тесты на классы Feline, Cat, Lion, LionAlex.
- Использованы моки и параметризация.
- Проведена оценка покрытия с помощью Jacoco.

## Структура проекта

```text
project/
    ├─ main/
    │   └─ java/     # классы   
    └─ test/
        └─ java/     # тесты
```

## Технологии

- Java 11
- Maven
- JUnit 4
- Mockito
- Jacoco

## Конфигурация и запуск

### Запуск

*mvn clean test*

### Получение отчёта

*mvn verify*
